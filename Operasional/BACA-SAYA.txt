Tombol operasional LestariPangan (klik dua kali):

  Nyalakan-LestariPangan.bat   menyalakan backend + tunnel (LP_TUNNEL di .env), lalu menampilkan status
  Matikan-LestariPangan.bat    mematikan backend dan tunnel
  Status-LestariPangan.bat     memeriksa backend, tunnel, situs publik, AI, mulai-otomatis
  Cadangkan-Data.bat           menyalin data ke folder backups
  Buka-Dashboard.bat           membuka dashboard Server di peramban (perlu login admin)
  Aktifkan-Otomatis.bat        menyala sendiri saat masuk Windows
  Batalkan-Otomatis.bat        membatalkan mulai-otomatis

Pengaturan ada di berkas .env di folder utama (lihat .env.example).
Tombol Jeda/Buka layanan, batas AI, dan pemantauan ada di dashboard Server (menu Server, login admin).
